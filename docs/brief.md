# Project Brief

[English](#english) | [中文](#zh)

<a id="english"></a>
## English

`web3-opportunity-scout` is a production-oriented skill for discovering early Web3 opportunities from configurable data sources.

It is designed to support:

- interactive chat queries
- scheduled push updates
- stateful deduplication across runs
- source-by-source extensibility

Its core value is a durable workflow rather than one-off summarization:

- collect raw signals
- normalize them into shared project records
- rank high-signal opportunities
- preserve memory, watchlists, and delivery history

<a id="zh"></a>
## 中文

`web3-opportunity-scout` 是一个面向生产环境的 Web3 早期机会发现 skill，目标是从可配置的数据源中稳定产出高价值机会线索。

它围绕下面几类能力设计：

- 对话式查询
- 定时推送
- 跨 run 的状态记忆与去重
- 按 source 扩展的数据接入

它的核心价值不是一次性摘要，而是一条可持续运行的流程：

- 收集原始信号
- 规范化成统一项目记录
- 对高信号机会进行排序
- 持续维护 memory、watchlist 和 delivery history
